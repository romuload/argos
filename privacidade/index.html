Privacidade, com clareza.

Este site apresenta a ArgosAI e permite preparar um resumo de projeto no seu dispositivo.

O que acontece com o briefing?

Os dados preenchidos são usados apenas no navegador para gerar o arquivo que você escolhe baixar. Não são enviados à ArgosAI, nem armazenados em banco de dados ou no armazenamento local do navegador.

Recursos externos

O site utiliza componentes, fontes e ícones do Porsche Design System. Ao carregar esses recursos, seu navegador se conecta à infraestrutura do fornecedor. A hospedagem também pode registrar informações técnicas de acesso. Não adicionamos ferramentas de publicidade ou análise de audiência.

Nota desta versão: o parágrafo anterior descreve o site original. Esta reconstrução usa a fonte Inter, imagens, vídeo e demais recursos hospedados no próprio site, sem carregar o Porsche Design System nem serviços de terceiros. A hospedagem no GitHub Pages pode registrar informações técnicas de acesso.

Canal comercial

O endereço comercial está em preparação. Quando a recepção de mensagens for ativada, esta página será atualizada para explicar o tratamento dessas informações.
